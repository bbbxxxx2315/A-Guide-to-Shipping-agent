你 24 小时里的"角色切换" // 02
06:00 预报员

检查所有 ETA 变更邮件，向引航站、码头、加油商三方确认计划。

10:00 单证员

在单一窗口提交进口岸申请，核对舱单与提单号，准备 7 份正本单证。

13:00 联检协调员

陪同海关、边检、海事、检疫四家登轮，3 小时内完成查验放行。

18:00 现场调度

在码头前沿监督引航、拖轮、系解缆，记录 SOF 装卸时间事实。

22:00 应急值班

处理船员突发疾病或加油延迟，30 分钟内通报船东与公司调度。

关键心法：外勤的工作节奏是"潮汐式"的 — 一个航次往往要在 6-12 小时内集中处理 70% 的事项。其余时间是预审、复盘、学习。
核心能力 01 / 03

口岸监管 & 法规合规

合规是外勤的"生命线"。一次漏报、一次错单，可能让船舶被扣、让公司被罚。

四口联检机制 // 01

船舶抵港后 24 小时内必须接受以下四家查验，任一环节不放行，船舶不能作业：

海关 Customs

核对舱单、申报货物、征收关税与增值税。

  • 关键单证：舱单、提单、装箱单、HS Code
  • 工具：单一窗口、中国电子口岸
海事局 MSA

船舶进出口岸审批、安全检查、配员核查。

  • 关键单证：国籍证书、最低配员证书
  • 工具：海事局一网通办
边检 Border

船员上下船管理、临时入境许可签发。

  • 关键单证：船员名单、护照、海员证
  • 工具：边检站现场办理
检疫 Quarantine

卫生检疫、动植物检疫、食品药品检验。

  • 关键单证：健康申明、疫苗接种证书
  • 工具：海关旅检系统
核心术语速查 // 02
ETDEstimated Time of Departure
预计离港时间。所有联检完成后才能更新到 ETD。变更必须 24h 前书面通报船东与租家。
NORNotice of Readiness
准备就绪通知书。船舶抵港后由船长/代理提交，是计时起算点。
SOFStatement of Facts
装卸时间事实记录。是后续滞期费/速遣费争议的核心证据。
HS CodeHarmonized System
海关商品编码。错一个码可能让税率从 0% 跳到 25%。
必须熟记的法规清单 // 03
  • 《中华人民共和国海关法》及其实施条例
  • 《中华人民共和国船舶登记条例》
  • 《国际船舶安全营运和防止污染管理规则》(ISM Code)
  • 《1974 年国际海上人命安全公约》(SOLAS)
  • 《1973/78 国际防止船舶造成污染公约》(MARPOL)
  • 《2006 年海事劳工公约》(MLC 2006)
新手提示：前三个月，建议每天花 15 分钟浏览中国海关总署官网与海事局官网的"政策法规"栏目，建立法规敏感度。
核心能力 02 / 03

船舶操作 & 港口流程

把一份靠离泊计划执行得滴水不漏 — 这是外勤"硬功夫"的部分。

船舶类型速识 // 01
集装箱船Container Ship
按 TEU 计量（20 英尺标准箱）。最大可达 24,000 TEU。外勤接触最多的船型。
散货船Bulk Carrier
运输煤炭、矿石、谷物。按载重吨 DWT 计量。常见巴拿马型、好望角型。
油轮Tanker
运输原油或成品油。VLCC 载重 30 万吨。外勤需特别熟悉防污染要求。
化学品船Chemical Tanker
运输液体化学品。对舱体涂层、洗舱程序有严苛要求。
靠离泊 14 步标准流程 // 02
1. 抵港前 24h

预审单证、确认 ETA、预报引航站与码头。

2. 抵港前 4h

提交进口岸申请，通知加油商、伙食供应商、废弃物接收方。

3. 抵港前 1h

引航员登船，启动引航作业。

4. 锚地等待

检疫 / 边检先遣人员登轮（如适用）。

5. 进港

拖轮协助、航道航行。

6. 靠泊

系解缆作业、碰垫检查、首尾缆系牢。

7. 联检

海关 / 边检 / 海事 / 检疫登轮，2-4 小时完成。

8. 加油加水

靠泊后即可开始，作业前签 SOF。

9. 装卸货

持续记录 SOF，异常立即通报船东。

10. 出口岸审批

离港前 4h 提交，由海事局放行。

11. 解缆

拖轮协助，拖至航道出口。

12. 离港

引航员下船，船舶开航。

13. 2h 内发结关小结

把全过程摘要发船东和公司调度。

14. 48h 内发结账单

港口使费 + 代理费明细，发船东结算部。

港口使费构成 // 03

外勤必须能看懂一份完整的港口账单，并能识别异常收费：

引航费 Pilotage拖轮费 Tug系解缆 Mooring码头费 Wharfage港务费 Harbor锚地费 Anchorage代理费 Agency加油 Bunker水 Water废弃物 Waste
省钱心法：同一艘船在 A 港与 B 港的使费可能相差 3 倍。外勤要在报价阶段就熟悉各港口费率，在议价阶段帮船东砍掉水分。
核心能力 03 / 03

客户沟通 & 应急处置

外勤是船东的"中国窗口"。你的每一封邮件、每一通电话，都在塑造客户对公司的印象。

航运英语 50 句核心模板 // 01
ETA 通报
"Pls be advised MV [name] ETA [port] [time] UTC, all cargo on board, all documents ready."
ETA 变更
"Revised ETA: [time] UTC due to [weather / port congestion / bunker delay]. Apologize for any inconvenience."
加油申请
"Kindly arrange delivery of [X]MT LSFO 380cst + [Y]MT MGO. Bunkers to commence after NOR tendered."
单证请求
"Pls provide crew list, port clearance docs and cargo manifest in advance for pre-clearance filing."

应急处置 · 独立带船

最后冲刺。从"导师带"到"独立接船" — 你要学会在压力下做正确决定。

5 类典型应急 // 01

案例 02 · 散货

巴拿马型散货船 · 装货监督

5.8 万吨镍矿从印尼运到中国，连云港卸货。

装货监督要点 // 01
  • 装前：检查货舱清洁度、测深管、压载水。核对装货图与提单数。
  • 装中：每 4 小时测一次水深，留取装货样品 3 份（船东 / 收货人 / 仲裁）。
  • 装后：大副水尺计量 + 岸上地磅对比。差异 > 0.5% 立即申诉。
  • SOF：装货时间、停水时间、装货速率、天气实况逐条记录。
  • 单证：提单、装货报告、品质证书、重量证书、大副收据。
争议预防清单 // 02
  • 装货前与发货人共同确认装货顺序
  • 装货中每小时核对实际装载量与计划
  • 每 8 小时与发货人代表沟通一次
  • 装货结束立刻在 SOF 上签字
  • 保留所有照片、监控、邮件作为凭证
核心心法：散货船 SOF 是法律证据。一旦签了字，几乎不可能推翻。装货过程中任何中断、等待、停水，都必须白纸黑字记下来。
案例 03 · 应急

船员突发疾病 · 3 小时送医

菲律宾籍大副在靠泊前 6 小时突发急性阑尾炎。

3 小时时间线 // 01
00:00 船上发现

二副报告大副右下腹剧痛，船长启动 Medical First Aid Guide。船上医疗官初步判断：疑似阑尾炎，需紧急下船。

00:15 外勤接到通知

船长通过卫星电话联系代理。我立即通报船东、调度、海关急救热线。

00:30 申请绿色通道

联系海关说明情况，申请"人道主义紧急下船"。海关 15 分钟内批准，要求补办单证。

00:45 120 调度

联系指定医院（涉外医疗资质），120 救护车 15 分钟内到码头。

01:00 翻译与单证

派英语 + 菲律宾语翻译各 1 名。准备：护照复印件、船上医疗记录、海关下船申请单。

02:00 救护车到位

靠泊 1 小时后，救护车在码头前沿等候。船医陪同大副下船。

02:30 入院手术

医院确诊急性阑尾炎，紧急手术。翻译全程陪同。

03:00 通报船东

完成 3 小时响应闭环。手术顺利，10 天后大副康复归船。

关键：每个港口都应该提前建立 3 件事 — 涉外医院清单、海关绿色通道联系人、120 急救响应路径。应急时省下的不是 3 小时，可能是一条命。
案例 04 · 商务

港口使费争议 · 节省 32 万

逐条核对账单后，成功申诉 12 项错误收费。

发现的问题 // 01

某散货船挂靠青岛港后，收到港务局账单 1,280,000 元。逐条核对后发现：

常见问题 1：重复收费

"港务费" 与 "港口设施保安费" 部分项目重叠，实际应二选一。

常见问题 2：费率版本错误

用了上季度的旧费率，未及时更新。新费率已下调 8%。

常见问题 3：免费项目误收

国际中转船免征"引航附加费"，账单上却列了。

常见问题 4：量级错误

拖轮按 3 艘收，实际使用 2 艘。系解缆按 24 根收，实际 18 根。

申诉 5 步流程 // 02
1. 收集证据

SOF、引航单、拖轮调度单、系解缆单、海事局申报回执。

2. 写申诉函

逐条列出争议项目，附法规依据 + 证据。英文 + 中文双语。

3. 提交港口调度

书面提交 + 现场拜访港口商务部门。

4. 谈判与折中

港口通常会承认 70-80% 错误，进行折扣谈判。

5. 复核 + 修订账单

确认新账单金额后，结算给船东。

结果：最终账单从 1,280,000 元 降至 960,000 元，为船东节省 32 万。客户后续 3 年的代理合同直接续约。

检查现场 5 个应对技巧 // 02
  • 不抢答：检查官问什么答什么，不要主动暴露额外信息。
  • 不争辩：对检查官的不同观点，礼貌说明事实，不正面冲突。
  • 不拖延：需要调取的文件 5 分钟内提供，否则会被记录"配合度低"。
  • 带笔记本：记录检查官问的每个问题，便于事后整改。
  • 保持微笑：态度比技术细节更重要。
关键：PSC 检查的心理准备比技术准备更重要。提前 48h 与船长召开 30 分钟简会，明确分工，往往比突击补课更有效。

SOLAS 公约强制要求：每个集装箱在装船前必须申报总重（Verified Gross Mass）。

两种申报方式 // 01
  • Method 1：整体称重（货物 + 集装箱 + 包装材料）
  • Method 2：分项累加（货物重量 + 集装箱自重 + 包装重量）
关键时点：VGM 必须在船舶截关前 24h提交。迟交 → 整箱不能装船 → 货主索赔。

林越 · 前外勤 / 现运营经理

12 年从外勤做到运营经理，下面是他在新员工培训里反复讲的一段话。

前 3 个月，把每艘船当作自己的船 // 01

"我刚入行的时候，师傅跟我说过一句话：前 3 个月，把每一艘船都当作自己的船。不是老板的船，不是公司的船，是你的船。"

"这句话的意思是：你在乎的应该是这艘船的航线、这批货的安全、这个船长的健康、这次航次的成本，而不是'这事儿归谁管'。"

"做到这一点，你就已经超过了 80% 的同龄人。做到第 12 个月，公司会主动给你加薪。做到第 3 年，你会发现自己有了'船感' — 看一眼 AIS 就能判断出 ETA 准不准。"

行业洞察 01 / 04

2026 全球航运趋势：绿色燃料与智能船舶

IMO 2050 净零排放目标正在重塑整个行业。

3 大趋势 // 01
  • 绿色燃料转型：甲醇 / 氨 / 氢燃料新船订单占比已超 30%。LSFO 380cst 将逐步淘汰。
  • 智能船舶：远程操控、自动避碰、数字孪生 — 2027 年起将批量出现"无人机舱"船舶。
  • 碳关税：欧盟 ETS 已把航运纳入，2026 年起中国-欧线需购买碳配额。
对外勤的影响：新一代船舶需要新的单证和报表（碳排放数据 / 燃料追溯）。建议现在就开始学 IMO DCS 与 EU MRV 体系。
行业洞察 02 / 04

中国新版《海运固体散装货物安全监督管理规定》解读

2025 年底发布，对散货船外勤有直接影响。

4 大变化 // 01
  • 取样要求：由 1 份样品改为 3 份（船东 / 收货人 / 第三方），留存 6 个月。
  • 水分检测：可流动性试验 (FMT) 与水分含量 (MC) 必填。
  • 平舱要求：明确禁止"集中装载"，违规罚款 5-10 万。
  • 事故报告：货物移动导致倾斜超过 5° 必须在 24h 内报告。
